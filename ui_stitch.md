# Fantasy CricManager - Initial Stitch Prompt

*Copy and paste the following prompt into Stitch to generate the first screen.*

**Prompt:**

Create a beautiful, modern, and highly responsive "Dashboard/Home" screen for a Fantasy Cricket Management simulation game. The vibe should be immersive, sporty, and slightly analytical, using a dark mode theme with vibrant accent colors (like gold/amber for primary actions and bright green for positive stats). 

**Key Requirements:**
1.  **Mobile-First & Responsive:** The layout must be perfectly usable on a small mobile screen (using stacked layouts) but expand intelligently for desktop (using side-by-side columns). Use Tailwind CSS for styling.
2.  **Global Navigation:** Include a sleek, sticky bottom navigation bar for mobile with icons for "Home", "Squad", "Match", and "Auction". On desktop, this should transform into a clean top navigation bar.
3.  **Top Header:** A user profile area showing the Manager's Name, Team Logo placeholder, and current "Budget: $100,000" in a prominent, highly visible, monospaced font.
4.  **Core Content Area (Mobile View):**
    *   **Upcoming Match Card:** A visually striking card at the top showing "Your Team vs. Orc Raiders", match day "Day 1", and a primary "Simulate Match" button.
    *   **Quick Stats:** A small grid displaying recent form (e.g., W-W-L), total fans, and current league standing.
    *   **Action Panel:** Quick links to "Manage Squad" and "View Schedule".
5.  **Desktop Expansion:** On wider screens, the "Upcoming Match Card" should be central, with "Quick Stats" moving to a left sidebar and the "Action Panel" expanding into a right-hand column showing upcoming tournament fixtures.

Ensure the UI feels like a polished, premium sports management game. Use modern sans-serif typography.
